# CurlPlan — iOS (SwiftUI)

Native SwiftUI port of the **CurlPlan Hi-Fi concept** ("Passport + Locker Room").
The web build lives at the repo root (deployed to GitHub Pages); this is the native
iOS version of the same design.

## Requirements
- macOS with **Xcode 15.4+**
- iOS **17.0+** (deployment target)

## Open & run
1. Open `ios/CurlPlan.xcodeproj` in Xcode.
2. Pick the **CurlPlan** scheme + an iPhone simulator (e.g. iPhone 15 Pro).
3. Press ⌘R.

No third-party dependencies, no package resolution — pure SwiftUI.

## Layout
| File | Role |
|------|------|
| `CurlPlan/CurlPlanApp.swift` | App entry, environment wiring |
| `Theme.swift` | Color tokens (Ice/Arena), fonts, persisted `AppSettings` |
| `Models.swift` | Data models, `Store`, seed season data |
| `Components.swift` | `HouseRing`, avatars, pebble texture, card style, pills |
| `RootView.swift` | Custom tab bar + per-tab `NavigationStack` + routing |
| `PassportView.swift` | Home: telemetry, season map, recent stops |
| `LockerRoomView.swift` | Feed: results, shared spiels, club reviews |
| `StopDetailView.swift` | Stop: ice read, games here, people met |
| `CurlerProfileView.swift` | Person: stats, shared clubs, recent form |
| `SpielsView.swift` / `RosterView.swift` | Season schedule / local roster |
| `SettingsSheet.swift` | Appearance sheet (theme / accent / pebble) |

## Notes
- **Fonts:** the concept uses Instrument Serif / Hanken Grotesk / DM Mono. Those
  aren't bundled, so the app maps to the closest system designs (New York serif, SF,
  SF Mono). To match exactly, add the `.ttf` files to the target, register them under
  `UIAppFonts` in Info.plist, and swap the helpers in `Theme.swift` to `.custom(...)`.
- **Project file:** `CurlPlan.xcodeproj/project.pbxproj` is generated by
  `generate-xcodeproj.js`. After adding/removing Swift files, re-run
  `node generate-xcodeproj.js` to rewire the target.
- **Authored on Windows (no Xcode):** this code has not been compiled here. If the
  project ever fails to open, the 60-second fallback is: in Xcode, File ▸ New ▸
  Project ▸ iOS App (SwiftUI, named `CurlPlan`), delete its generated
  `ContentView.swift` + `CurlPlanApp.swift`, then drag every file from
  `ios/CurlPlan/` into the project.

## Parity with the web build
Same six screens, house-ring system, Ice/Arena theming, accent + pebble settings,
tab navigation, and push-to-detail (stop / curler) flows. Local roster state is live
across Roster, profiles, and stop detail.
